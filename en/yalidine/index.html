Yalidine API for Node.js and PHP

Create, track and price your Yalidine parcels (and GuepEx, same platform) with the dz-delivery SDK — no hand-written HTTP calls, pagination or status mapping.

Install

TypeScript · npm
npm install @dz-delivery/core
PHP · Composer
composer require dz-delivery/sdk

Node.js ≥ 18 (zero dependencies) or PHP ≥ 8.2 (Guzzle 7). The same code then works with the other carriers: only the client configuration changes.

Yalidine with TypeScript / Node.js

TypeScript
import { createClient, isShippingError } from '@dz-delivery/core';

const yalidine = createClient('yalidine', {
  apiId: process.env.YALIDINE_API_ID!,
  apiToken: process.env.YALIDINE_API_TOKEN!,
  fromWilayaId: 16, // origin wilaya (Algiers)
});

// Wilayas, communes, offices (stop desks)
const wilayas = await yalidine.getWilayas();            // id = official code 1–58
const communes = await yalidine.getCommunes(16);
const desks = await yalidine.getStopDesks({ wilayaId: 31 });

// Delivery fees (weight in kg, dimensions in cm)
const quote = await yalidine.getFees({ toWilayaId: 31, weight: 2 });
// { deliveryFee, stopDeskFee, returnFee?, currency: 'DZD' }

// Create a parcel (cash on delivery)
try {
  const parcel = await yalidine.createParcel({
    recipientName: 'Mohamed Amine',
    phone: '0550123456',
    address: 'Cité 221 lots, n°98',
    wilayaName: 'Oran',
    communeName: 'Bir El Djir',
    productName: 'T-shirt',
    price: 2500,
    orderId: 'ORDER-1001',
  });

  // Tracking: unified status + history (oldest first)
  const { parcel: current, events } = await yalidine.track(parcel.trackingNumber);
  console.log(current.status, events.at(-1)?.label);
} catch (err) {
  if (isShippingError(err)) console.error(err.code, err.message, err.details);
}

Yalidine with PHP / Laravel

PHP
use DzDelivery\ClientFactory;
use DzDelivery\Errors\ShippingError;

$yalidine = ClientFactory::create('yalidine', [
    'apiId'        => getenv('YALIDINE_API_ID'),
    'apiToken'     => getenv('YALIDINE_API_TOKEN'),
    'fromWilayaId' => 16, // or 'fromWilayaName' => 'Alger'
]);

$wilayas = $yalidine->getWilayas();
$desks   = $yalidine->getStopDesks(['wilayaId' => 31]);
$quote   = $yalidine->getFees(['toWilayaId' => 31, 'weight' => 2]);

try {
    $parcel = $yalidine->createParcel([
        'recipientName' => 'Mohamed Amine',
        'phone'         => '0550123456',
        'address'       => 'Cité 221 lots, n°98',
        'wilayaName'    => 'Oran',
        'communeName'   => 'Bir El Djir',
        'productName'   => 'T-shirt',
        'price'         => 2500,
        'orderId'       => 'ORDER-1001',
    ]);

    $result = $yalidine->track($parcel->trackingNumber);
    echo $result->parcel->status; // pending | in_transit | delivered | ...
} catch (ShippingError $e) {
    echo "{$e->code}: {$e->getMessage()}";
}

Supported methods

MethodSupportNotes
createParcelyesNew parcels are « En préparation » (being prepared) → pending.
trackyesUnified status + full history. parcel.labelUrl = link to the shipping label (also returned by createParcel).
getFeesyesVolumetric weight is billed when it is higher (length / width / height in cm).
getWilayas / getCommunesyesThe wilaya id is the official code.
getStopDesksyesYalidine offices (centers), communeId optional.
listParcelsyesGET /parcels/, up to 1000 per page. keyword → tracking, orderId → order_id; 50 by default. status and updatedSince are filtered by the SDK page by page: a page can be short (or empty) while hasNext is true, so keep following hasNext.
cancelParcelyesOnly parcels still « En préparation » (being prepared).
healthCheckyesChecks the credentials (real API call).

GuepEx API

GuepEx runs the same API as Yalidine on a different domain. Use the yalidine provider with your GuepEx credentials and the GuepEx URL:

TypeScript
import { createClient, GUEPEX_DEFAULT_BASE_URL } from '@dz-delivery/core';

const guepex = createClient('yalidine', {
  apiId: process.env.GUEPEX_API_ID!,
  apiToken: process.env.GUEPEX_API_TOKEN!,
  fromWilayaId: 16,
  baseUrl: GUEPEX_DEFAULT_BASE_URL, // https://api.guepex.app/v1
});
PHP
use DzDelivery\ClientFactory;
use DzDelivery\Providers\YalidineProvider;

$guepex = ClientFactory::create('yalidine', [
    'apiId'        => getenv('GUEPEX_API_ID'),
    'apiToken'     => getenv('GUEPEX_API_TOKEN'),
    'fromWilayaId' => 16,
    'baseUrl'      => YalidineProvider::GUEPEX_DEFAULT_BASE_URL,
]);

Good to know about the Yalidine API

  • Origin wilaya required: without fromWilayaId / fromWilayaName, createParcel and getFees throw VALIDATION_ERROR.
  • Wilaya and commune can be passed by id, official code or name: the SDK resolves them before the HTTP call.
  • The Yalidine tracking number doubles as the identifier (parcel.id === parcel.trackingNumber).
  • Pagination (page_size = 1000) and non-deliverable wilayas/communes are handled for you.
  • When you hit the rate limit, the RATE_LIMITED error tells you how long to wait (retryAfter) when Yalidine sends it.

Detailed native mapping (endpoints, fields, statuses): PROVIDERS.md.

Yalidine FAQ

How do I get a Yalidine API key?

In your Yalidine merchant account, developer section: you will find the API ID and the API token to pass as apiId and apiToken.

How do I calculate Yalidine delivery fees?

getFees({ toWilayaId, weight }) returns deliveryFee (home) and stopDeskFee (office) in DZD, from your origin wilaya.

How do I ship a parcel to a Yalidine office (stop desk)?

List the offices with getStopDesks({ wilayaId }), then create the parcel with isStopDesk: true and stopDeskId = the office id.

Does the SDK work with GuepEx?

Yes, see the GuepEx API section: same provider, different baseUrl.
