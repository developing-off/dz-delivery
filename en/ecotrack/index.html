Ecotrack API — DHD, Anderson, World Express… for Node.js and PHP

Ecotrack is the platform behind DHD, Anderson, World Express and dozens of other Algerian couriers. With dz-delivery, a single ecotrack provider covers them all.

Install

TypeScript · npm
npm install @dz-delivery/core
PHP · Composer
composer require dz-delivery/sdk

Node.js ≥ 18 (zero dependencies) or PHP ≥ 8.2 (Guzzle 7). Every carrier implements the same interface, so the same code works with the others once the client is configured; some operations are not available on every carrier and throw NOT_SUPPORTED (see the capability matrix).

Ecotrack with TypeScript / Node.js

TypeScript
import { createClient, isShippingError } from '@dz-delivery/core';

const dhd = createClient('ecotrack', {
  token: process.env.ECOTRACK_TOKEN!,
  courier: 'dhd',              // or baseUrl: 'https://<tenant>.ecotrack.dz'
  autoValidate: true,          // hand the order over to the courier right away
});

try {
  const wilayas = await dhd.getWilayas();        // wilayas served by this courier
  const desks = await dhd.getStopDesks({ wilayaId: 16 });
  const quote = await dhd.getFees({ toWilayaId: 16 });

  const parcel = await dhd.createParcel({
    recipientName: 'Mohamed Amine',
    phone: '0550123456',
    address: 'Cité 221 lots, n°98',
    wilayaId: 16,
    communeName: 'Bab Ezzouar',
    productName: 'T-shirt',
    price: 2500,
    orderId: 'ORDER-1001',
  });

  const { parcel: current, events } = await dhd.track(parcel.trackingNumber);
} catch (err) {
  if (isShippingError(err)) console.error(err.code, err.message);
}

Ecotrack with PHP / Laravel

PHP
use DzDelivery\ClientFactory;
use DzDelivery\Errors\ShippingError;

$dhd = ClientFactory::create('ecotrack', [
    'token'        => getenv('ECOTRACK_TOKEN'),
    'courier'      => 'dhd',  // or 'baseUrl' => 'https://<tenant>.ecotrack.dz'
    'autoValidate' => true,
]);

try {
    $quote = $dhd->getFees(['toWilayaId' => 16]);

    $parcel = $dhd->createParcel([
        'recipientName' => 'Mohamed Amine',
        'phone'         => '0550123456',
        'address'       => 'Cité 221 lots, n°98',
        'wilayaId'      => 16,
        'communeName'   => 'Bab Ezzouar',
        'productName'   => 'T-shirt',
        'price'         => 2500,
        'orderId'       => 'ORDER-1001',
    ]);

    $result = $dhd->track($parcel->trackingNumber);
} catch (ShippingError $e) {
    echo "{$e->code}: {$e->getMessage()}";
}

Good to know about the Ecotrack API

  • Validation: without autoValidate: true, orders stay on hold until they are validated in the courier’s dashboard.
  • cancelParcel only works before validation; after that the API returns VALIDATION_ERROR.
  • The id of communes and stop desks is the Ecotrack postal code (“station code”): use it as-is for stopDeskId.
  • A baseUrl ending in /api/v1 is accepted (the suffix is stripped automatically).

Detailed native mapping (endpoints, fields, statuses): PROVIDERS.md.

Ecotrack FAQ

How do I integrate the DHD API?

DHD runs on Ecotrack: create an ecotrack client with your DHD token and courier: 'dhd'.

My courier uses Ecotrack but is not in the list?

Pass its tenant URL as baseUrl (e.g. https://mycourier.ecotrack.dz); the API is identical.

Why do my Ecotrack parcels stay on hold?

Ecotrack creates orders unvalidated. Turn on autoValidate: true or validate them from the courier’s dashboard.
