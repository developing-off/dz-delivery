Maystro Delivery API for Node.js and PHP

Create Maystro orders, calculate fees and list pickup points with the dz-delivery SDK. Track, list and cancel orders through the API, or receive status updates by webhook.

Install

TypeScript · npm
npm install @dz-delivery/core
PHP · Composer
composer require dz-delivery/sdk

Node.js ≥ 18 (zero dependencies) or PHP ≥ 8.2 (Guzzle 7). The same code then works with the other carriers: only the client configuration changes.

Maystro with TypeScript / Node.js

TypeScript
import { createClient, isShippingError } from '@dz-delivery/core';

const maystro = createClient('maystro', {
  apiToken: process.env.MAYSTRO_API_TOKEN!,
});

const wilayas = await maystro.getWilayas();
const communes = await maystro.getCommunes(16);

// Stop desks / pickup points: Maystro requires communeId
const desks = await maystro.getStopDesks({ wilayaId: 16, communeId: communes[0].id });

const quote = await maystro.getFees({ toWilayaId: 16, toCommuneId: communes[0].id });

try {
  const parcel = await maystro.createParcel({
    recipientName: 'Mohamed Amine',
    phone: '0550123456',
    address: 'Cité 221 lots, n°98',
    wilayaId: 16,
    communeName: 'Bab Ezzouar',
    productName: 'T-shirt',
    price: 2500,
    orderId: 'ORDER-1001',
  });
  // use parcel.trackingNumber (or parcel.id) for track / cancelParcel
  const { events } = await maystro.track(parcel.trackingNumber);
} catch (err) {
  if (isShippingError(err)) console.error(err.code, err.message);
}

Maystro with PHP / Laravel

PHP
use DzDelivery\ClientFactory;

$maystro = ClientFactory::create('maystro', [
    'apiToken' => getenv('MAYSTRO_API_TOKEN'),

$communes = $maystro->getCommunes(16);
$desks    = $maystro->getStopDesks(['wilayaId' => 16, 'communeId' => $communes[0]->id]);

    'productName'   => 'T-shirt',

Print shipping labels (PDF)

TypeScript
import { MaystroProvider } from '@dz-delivery/core';
import { writeFileSync } from 'node:fs';

const maystro = new MaystroProvider({ apiToken: process.env.MAYSTRO_API_TOKEN! });
const { data, labelCount } = await maystro.getLabels(['172316976800001']); // tracking numbers or parcel.id
writeFileSync('labels.pdf', data); // one page per order found
PHP
use DzDelivery\Models\ClientOptions;
use DzDelivery\Providers\MaystroProvider;

$maystro = new MaystroProvider(ClientOptions::fromArray(['apiToken' => getenv('MAYSTRO_API_TOKEN')]));
$labels  = $maystro->getLabels(['172316976800001']); // tracking numbers or $parcel->id
return response($labels->data, 200, ['Content-Type' => 'application/pdf']); // Laravel

Track Maystro parcels with webhooks

Set up an HTTPS URL in the Maystro app (Settings → Webhooks). The OrderStatusChanged event carries payload.id (the order id) and payload.status (a numeric code), which the SDK converts to a unified status.

TypeScript
import { mapMaystroStatus } from '@dz-delivery/core';

// event = JSON decoded from message.data (base64)
if (event.event === 'OrderStatusChanged') {
  const status = mapMaystroStatus(event.payload.status); // 41 → 'delivered'
  // update the order whose carrier_id = event.payload.id
}
PHP
use DzDelivery\Support\StatusMapper;

if (($event['event'] ?? null) === 'OrderStatusChanged') {
    $status = StatusMapper::maystro($event['payload']['status'] ?? null); // 41 → 'delivered'
}

Full example (base64 decoding, securing the URL): PHP guide, Maystro webhooks section.

Good to know about the Maystro API

  • track and cancelParcel accept the order id (parcel.id) or the tracking number (the Maystro display_id, one extra request).
  • listParcels: Maystro returns 20 orders per page with no filtering; the SDK filters each page (status, orderId, keyword, updatedSince).
  • getStopDesks requires a communeId; the returned id is what you pass as stopDeskId when creating a parcel.
  • Fees come from the Maystro pricing API, with an automatic fallback to the legacy delivery-options API.
  • Maystro webhooks are not signed: protect the URL (for example with a long secret in the query string).

Detailed native mapping (endpoints, fields, statuses): PROVIDERS.md.

Maystro FAQ

How do I track a Maystro parcel through the API?

With track(): the SDK reads the order and its history (history_order) and returns unified statuses. To get notified without polling the API, use webhooks: the SDK provides mapMaystroStatus / StatusMapper::maystro() to convert them to unified statuses.

Where do I find the Maystro API token?

It is your store token in the Maystro app; pass it as-is in apiToken.

How do I calculate Maystro fees?

getFees({ toWilayaId, toCommuneId }) returns the home rate (deliveryFee) and the stop desk rate (stopDeskFee) in DZD.
