dz-delivery

Un seul SDK pour créer, suivre et tarifer des colis avec les transporteurs algériens — TypeScript et PHP, même contrat.

Installer Voir le dépôt

Interface unifiée

Cinq opérations. Tous les transporteurs.

Pas un wrapper 1:1 de chaque API — juste ce dont une boutique a besoin, avec les mêmes noms en TS et en PHP.

  1. 01 Créer un colis createParcel
  2. 02 Suivre un envoi track
  3. 03 Coter les frais getFees
  4. 04 Wilayas, communes, stop desks getWilayas · getCommunes · getStopDesks
  5. 05 Annuler un colis cancelParcel

Installer

Packages publiés sur npm et Packagist.

TypeScript · npm 
npm install @dz-delivery/core
PHP · Composer 
composer require dz-delivery/sdk
import { createClient } from '@dz-delivery/core';

const shipping = createClient('zrexpress', {
  apiKey: process.env.ZREXPRESS_API_KEY!,
  tenant: process.env.ZREXPRESS_TENANT!,
});

const parcel = await shipping.createParcel({
  recipientName: 'Amine B.',
  phone: '0550123456',
  address: '12 rue Didouche Mourad',
  wilayaId: 16,
  communeName: 'Alger Centre',
  productName: 'T-shirt',
  price: 2500,
});
use DzDelivery\ClientFactory;

$shipping = ClientFactory::create('zrexpress', [
    'apiKey' => getenv('ZREXPRESS_API_KEY'),
    'tenant' => getenv('ZREXPRESS_TENANT'),
]);

$parcel = $shipping->createParcel([
    'recipientName' => 'Amine B.',
    'phone'         => '0550123456',
    'address'       => '12 rue Didouche Mourad',
    'wilayaId'      => 16,
    'communeName'   => 'Alger Centre',
    'productName'   => 'T-shirt',
    'price'         => 2500,
]);
