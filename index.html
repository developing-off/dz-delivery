dz-delivery

Un seul SDK pour créer, suivre et tarifer des colis avec les transporteurs algériens — TypeScript et PHP, même contrat.

Installer Voir l’usage

Interface unifiée

Cinq opérations. Tous les transporteurs.

Pas un wrapper 1:1 de chaque API — juste ce dont une boutique a besoin, avec les mêmes noms en TS et en PHP.

  1. 01 Créer un colis createParcel
  2. 02 Suivre un envoi track
  3. 03 Coter les frais getFees
  4. 04 Wilayas, communes, stop desks getWilayas · getCommunes · getStopDesks
  5. 05 Annuler un colis cancelParcel

Installer

Packages publiés sur npm et Packagist.

TypeScript · npm 
npm install @dz-delivery/core
PHP · Composer 
composer require dz-delivery/sdk
import { createClient } from '@dz-delivery/core';

const shipping = createClient('zrexpress', {
  apiKey: process.env.ZREXPRESS_API_KEY!,
  tenant: process.env.ZREXPRESS_TENANT!,
});

const parcel = await shipping.createParcel({
  recipientName: 'Amine B.',
  phone: '0550123456',
  address: '12 rue Didouche Mourad',
  wilayaId: 16,
  communeName: 'Alger Centre',
  productName: 'T-shirt',
  price: 2500,
});
// parcel.trackingNumber · parcel.status · parcel.id
use DzDelivery\ClientFactory;

$shipping = ClientFactory::create('zrexpress', [
    'apiKey' => getenv('ZREXPRESS_API_KEY'),
    'tenant' => getenv('ZREXPRESS_TENANT'),
]);

$parcel = $shipping->createParcel([
    'recipientName' => 'Amine B.',
    'phone'         => '0550123456',
    'address'       => '12 rue Didouche Mourad',
    'wilayaId'      => 16,
    'communeName'   => 'Alger Centre',
    'productName'   => 'T-shirt',
    'price'         => 2500,
]);
// $parcel->trackingNumber · $parcel->status

Guide rapide

Comment bien l’utiliser

Le flux type d’une boutique : configurer le client, résoudre les lieux, coter, créer, suivre.

  1. 1

    Un client par transporteur. Passe les credentials du compte marchand. Options communes : timeoutMs, includeRaw, baseUrl.

  2. 2

    Wilaya / commune. Tu peux envoyer le code officiel 1–58, un id transporteur, ou un nom. Le SDK résout avant l’appel HTTP.

  3. 3

    Stop desk. Liste avec getStopDesks, puis isStopDesk: true + stopDeskId (l’id renvoyé).

  4. 4

    Stocke le tracking. Garde trackingNumber (et id si besoin d’annuler chez ZRExpress).

  5. 5

    Attrape ShippingError. Codes unifiés : auth, validation, not found, rate limit, not supported…

Yalidine / GuepEx exigent une wilaya d’origine : fromWilayaId (ou fromWilayaName) au client. Maystro : pas de track / cancelParcel (webhooks). Ecotrack : courier ou baseUrl HTTPS.

Tarifs, stop desks, suivi

Même surface pour tous les providers supportés. 

// Lieux (mis en cache sur le client)
const wilayas = await shipping.getWilayas();
const communes = await shipping.getCommunes(16);

// Tarifs — Yalidine utilise fromWilayaId du client
const quote = await shipping.getFees({
  toWilayaId: 16,
  toCommuneId: '1630', // recommandé Maystro / Yalidine
  isStopDesk: false,
});

// Points relais — Maystro : communeId obligatoire
const desks = await shipping.getStopDesks({
  wilayaId: 16,
  communeId: '1630',
});

const stopDeskParcel = await shipping.createParcel({
  /* … champs obligatoires … */
  isStopDesk: true,
  stopDeskId: desks[0].id,
});

const { parcel: current, events } = await shipping.track(stopDeskParcel.trackingNumber);
await shipping.cancelParcel(stopDeskParcel.trackingNumber);

await shipping.healthCheck(); // { ok, provider, latencyMs }
$wilayas = $shipping->getWilayas();
$communes = $shipping->getCommunes(16);

$quote = $shipping->getFees([
    'toWilayaId'  => 16,
    'toCommuneId' => 1630,
    'isStopDesk'  => false,
]);

$desks = $shipping->getStopDesks([
    'wilayaId'  => 16,
    'communeId' => 1630,
]);

$parcel = $shipping->createParcel([
    /* … */
    'isStopDesk' => true,
    'stopDeskId' => $desks[0]->id,
]);

$result = $shipping->track($parcel->trackingNumber);
$shipping->cancelParcel($parcel->trackingNumber);
$health = $shipping->healthCheck();

Erreurs

Toute échec lève ShippingError (TS : isShippingError). Ne catch pas les erreurs génériques sans lire code. 

import { isShippingError } from '@dz-delivery/core';

try {
  await shipping.createParcel(input);
} catch (err) {
  if (isShippingError(err)) {
    // AUTH_FAILED | VALIDATION_ERROR | NOT_FOUND | RATE_LIMITED
    // NOT_SUPPORTED | PROVIDER_ERROR | NETWORK_ERROR | UNKNOWN
    console.error(err.code, err.message, err.httpStatus, err.details);
    if (err.code === 'RATE_LIMITED' && err.retryAfter) {
      // attendre retryAfter secondes
    }
  }
  throw err;
}
use DzDelivery\Errors\ShippingError;

try {
    $shipping->createParcel($input);
} catch (ShippingError $e) {
    // $e->code · $e->httpStatus · $e->details · $e->retryAfter
    echo $e->code . ': ' . $e->getMessage();
}
